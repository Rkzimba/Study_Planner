# Lista de Estudos

Aplicação Front-End desenvolvida com **HTML**, **CSS** e **JavaScript** para praticar manipulação do DOM, eventos, validação de formulários e consumo de API, permitindo adicionar atividades manualmente e importar sugestões da JSONPlaceholder.

## Tecnologias

* HTML5
* CSS3
* JavaScript
* JSONPlaceholder API

## Funcionalidades

* Cadastro manual de atividades
* Consumo de sugestões da API
* Filtragem por User ID
* Lista dinâmica de estudos
* Recarregamento da última busca
* Validação básica de formulários
